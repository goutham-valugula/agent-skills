# Tailor an application without inventing

1. Read the job description and the user's supplied resume or experience notes. Identify required qualifications, useful qualifications, responsibilities, and any application questions.
2. Make a match table: job requirement, evidence from the user's materials, and strength or gap. Mark unsupported requirements as `no evidence provided`.
3. Suggest truthful changes to ordering, wording, and emphasis. Keep measurable results only when they appear in the source material or the user confirms them.
4. Draft requested sections in the user's voice. Do not invent employers, credentials, tools, dates, responsibilities, impact, or reasons for leaving.
5. Clearly list missing facts the user should confirm, especially dates, numbers, and eligibility answers.
6. Check that the final draft is relevant, readable, consistent with the source resume, and free of fabricated claims.
7. Return drafts only. Do not submit applications or contact employers.

## Output

Provide the strongest evidence-based match, suggested resume edits, any requested draft, and a short confirmation checklist.

## Example request

“Compare my resume with this role. Rewrite my summary and the most relevant three bullets, but keep every claim tied to something already in my resume. Tell me where I’m missing evidence.”
