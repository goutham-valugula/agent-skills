# Design & Development Skills

Choose a standalone workflow for planning, improving, or reviewing a digital interface. These skills work best with an AI coding agent that can inspect the project and, for visual verification, open its browser preview.

## Available

### [Design to ship reviewer](design-to-ship-reviewer/SKILL.md)

Turn a product brief or UI reference into a focused interface improvement, then inspect the rendered result at desktop and mobile sizes. The handoff distinguishes checks actually performed from anything that could not be verified.

**Useful for:** frontend developers, designers, product builders, and small teams who want an AI coding agent to improve a screen without blindly redesigning the whole product.

**Not for:** claiming pixel-perfect fidelity, accessibility certification, or production readiness without evidence; replacing human product or design judgment.

## Use only what you need

1. Open the individual skill folder above and review its `SKILL.md`.
2. Provide the relevant brief, design reference, or code project; share only the context required for the task.
3. Follow your AI assistant's current instructions for adding or supplying a skill. Platform and browser support varies.
4. Review the changes and evidence before shipping them to users.
