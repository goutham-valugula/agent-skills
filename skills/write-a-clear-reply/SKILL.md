# Draft a clear reply

1. Identify who will read the message, what the user wants to achieve, and the tone or length they prefer.
2. Use only facts and commitments the user supplied. If an essential fact is missing, use a visible placeholder or ask; never invent an excuse, promise, or personal detail.
3. Lead with the main point. Use plain language, short paragraphs, and a clear request or next step.
4. Match the relationship and urgency without sounding needlessly harsh, flattering, or formal.
5. Remove repeated context and jargon the recipient does not need.
6. Check names, dates, attachments mentioned, and promises against the supplied facts.
7. Return the message as a draft. Do not send, schedule, or post it unless the user separately and clearly authorizes that action and the connected tool confirms it.

## Output

Provide the draft first. Add a brief note for any placeholder or important choice of tone. Offer a shorter version only when it would help.

## Example request

“Write a polite but firm reply asking the landlord to confirm the repair date. The technician said they might come Thursday, but it isn’t confirmed. Don’t make it sound like I’m threatening legal action.”
